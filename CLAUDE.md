# CLAUDE.md

Personal site for `freax.games` (GitHub Pages, served from `master`). The old
`github.freaxnx01.ch` 301-redirects there.

- **Browser Games Hub** at the site root `freax.games/` — static root `index.html` +
  `style.css` + `filter.js` + `lightbox.js` + `assets/`. Screenshots are generated by
  `scripts/capture_screenshots.py`.
- `games/index.html` is a redirect stub: old `freax.games/games/` links forward to `/`
  (query and hash kept). The old landing page is `links.md` (Jekyll,
  `jekyll-theme-hacker`, served at `/links.html`).

Each game lives in its own `game-<name>` repo (GitHub Pages, root `index.html`),
is served at its own subdomain `https://<name>.freax.games/` (`<name>` = repo name
without `game-`), and gets a card in the hub `index.html` whose play link is that
subdomain. A new game gets its subdomain with
`python3 scripts/move_to_subdomain.py <name>` (maintainer session: needs the
Cloudflare token from Passbolt). Until then `<name>.freax.games` forwards to
`freax.games/<name>/` through a Cloudflare wildcard. Rhyflitzer has its own domain,
`rhyflitzer.ch`.

Every card also gets a short path `freax.games/<name>/`, a redirect stub generated by
`python3 scripts/make_short_links.py`. Rerun it after adding or removing a card and
commit the stubs with the card.

## Analytics (Umami)

Games get Umami analytics (umami.is), self-hosted on VPS DE. Tschau Sepp is the
first game to get it. Every game that gets the integration must name **Umami**
and the **server location (Germany)** in its privacy notice. If the game has no
privacy notice yet, add one as part of the integration. In dc games, put both
the snippet and the notice in the `.dc.html` source, not the generated
`index.html`.

Each game gets its own Umami website, created through the Umami API with the
Passbolt login „Umami admin stats.freaxnx01.ch". The tracker is the renamed
`https://stats.freaxnx01.ch/g.js` with
`data-domains="github.freaxnx01.ch,freax.games,<name>.freax.games"` (keep all three:
old hostnames still arrive via redirects).
Use the custom domain here: `freaxnx01.github.io` redirects to it, so it never
appears as the hostname. game-tschau-sepp PR #44 is the reference
implementation (`analytics.js` helper plus the events). Put the privacy link in
the game's own menu, not in `#game-nav`. A wider nav covers game buttons at
1280×720.

Umami's dashboard counts each event property separately. For one row per round
with all players and scores, run `python3 scripts/umami_rounds.py` (`--since 30d`,
`--online`, `--csv`).

## Testhub

`/testhub/` lists each game's open `test-todo.md` items, jumps the game to the
place an item is about and exports notes with Copy all. Spec: `freaxnx01/game-rhyflitzer`
`docs/superpowers/specs/2026-10-11-testhub-design.md`. Add a game by appending its
slug to `GAMES` in `testhub/app.js`. A game loads `/testhub/client.js` async in dev
mode only (`?dev=1`) and registers after the `gg-testhub-ready` event (contract in
the header comment of `testhub/client.js`). Items are tagged `{go: <id>}`.
Tests: `node --test tests/testhub/*.test.mjs` and `.venv/bin/pytest tests/test_testhub_e2e.py`.
