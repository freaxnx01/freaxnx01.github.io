# Game dev resources

Shared bookmarks for all `game-*` repos: engines, libraries, assets, tools.
One line per entry: link, what it is, and which game uses it (if any).

Format:

```
- [Name](url) — what it is / why it's useful. License: X. Used in: game-foo
```

## Physics engines

- [crashcat](https://github.com/isaac-mason/crashcat) — JS physics engine built for games, simulations and creative websites. License: MIT. Used in: game-kit-racer, game-rhyflitzer

## Rendering / game frameworks

- [three.js](https://threejs.org/) — 3D library for WebGL/WebGPU. License: MIT. Used in: game-barrel-shooter, game-kit-racer, game-rhyflitzer, game-splashdown, game-toepferscheibe, game-voxel-sandbox, game-wipfelkratzer

## Asset libraries

### Sprites & 3D models

- [Quaternius](https://quaternius.com/) — low-poly 3D model packs (characters, nature, vehicles). License: CC0. Used in: game-rhyflitzer
- [Kenney](https://kenney.nl/) — large 2D/3D/UI/audio asset packs. License: CC0. Used in: game-kit-racer, game-rhyflitzer
