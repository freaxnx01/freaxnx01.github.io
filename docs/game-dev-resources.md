# Game dev resources

Shared bookmarks for all `game-*` repos: engines, libraries, assets, tools.
One line per entry: link, what it is, and which game uses it (if any).

Format:

```
- [Name](url) — what it is / why it's useful. License: X. Used in: game-foo
```

## Physics engines

- [crashcat](https://github.com/isaac-mason/crashcat) — JS physics engine built for games, simulations and creative websites. License: MIT. Used in: game-kit-racer, game-rhyflitzer
- [cannon-es](https://github.com/pmndrs/cannon-es) — lightweight 3D rigid-body physics, pairs well with three.js. License: MIT. Used in: game-barrel-shooter

## Rendering / game frameworks

- [three.js](https://threejs.org/) — 3D library for WebGL/WebGPU. License: MIT. Used in: game-barrel-shooter, game-kit-racer, game-rhyflitzer, game-splashdown, game-toepferscheibe, game-voxel-sandbox, game-wipfelkratzer

## Asset libraries

### Sprites & 3D models

- [Quaternius](https://quaternius.com/) — low-poly 3D model packs (characters, nature, vehicles). License: CC0. Used in: game-rhyflitzer
- [Kenney](https://kenney.nl/) — large 2D/3D/UI/audio asset packs. License: CC0. Used in: game-kit-racer, game-rhyflitzer

- [swissBUILDINGS3D 3.0](https://www.swisstopo.admin.ch) — 3D building models of Switzerland from swisstopo. License: Open Government Data, attribution required. Used in: game-rhyflitzer

### Icons

- [Phosphor Icons](https://phosphoricons.com/) — flexible icon family (web font / SVG). License: MIT. Used in: game-brickfall

### Audio & music

### Fonts

- [Google Fonts](https://fonts.google.com/) — free web fonts, mostly OFL. Most used: Bungee (17 games); also Nunito, Baloo 2, Russo One, Press Start 2P, Jost, Fredoka

### Maps & geo data

- [d3](https://d3js.org/) — data visualisation, used here for map projections. License: ISC. Used in: game-geography-quiz
- [topojson-client](https://github.com/topojson/topojson-client) — decode TopoJSON to GeoJSON. License: ISC. Used in: game-geography-quiz
- [world-atlas](https://github.com/topojson/world-atlas) / [us-atlas](https://github.com/topojson/us-atlas) — ready-made world and US TopoJSON from Natural Earth / Census. License: ISC. Used in: game-geography-quiz
- [swiss-maps](https://github.com/interactivethings/swiss-maps) — Swiss cantons/municipalities as TopoJSON. Used in: game-geography-quiz

## Other libraries

- [PeerJS](https://peerjs.com/) — WebRTC peer-to-peer, for online multiplayer without own server. License: MIT. Used in: game-wortduell
- [TensorFlow.js](https://www.tensorflow.org/js) — ML in the browser. License: Apache-2.0. Used in: game-gorillazz
- [Magenta.js](https://magenta.tensorflow.org/js) — music/ML models on top of TensorFlow.js. License: Apache-2.0. Used in: game-gorillazz
